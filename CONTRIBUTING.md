# Contribution Guidelines

Спасибо за интерес к улучшению **Awesome GigaCode**! Пожалуйста, ознакомьтесь с правилами ниже, прежде чем создавать Pull Request (PR).

## Добавление в список

Чтобы ваше предложение было принято, убедитесь, что PR соответствует следующим требованиям:

- **Поиск дубликатов:** Проверьте, нет ли уже вашей ссылки в списке или в открытых PR. Дубликаты будут отклоняться.
- **Полезность:** Ссылка должна быть действительно полезной и проверенной вами лично. Не добавляйте всё подряд.
- **Один PR — одна ссылка:** Создавайте отдельный Pull Request для каждого предложения. Не смешивайте несколько ссылок в одном PR.
- **Формат:** Используйте строгий формат: `- [Название](ссылка) - Краткое описание.`
    - Описание обязательно. Оно должно объяснять, **почему** эта ссылка полезна, а не просто пересказывать название.
    - Название и описание начинаются с заглавной буквы.
    - Описание заканчивается точкой.
- **Расположение:** Добавляйте новую ссылку в конец соответствующего раздела (категории), а не в случайное место.
- **Заголовок PR:** Заголовок вашего Pull Request должен быть осмысленным (например, `Add GigaCode CLI commands guide`). Заголовки вида `Update README.md` будут закрываться без рассмотрения.
- **Грамматика и форматирование:** Проверьте орфографию и пунктуацию. Убедитесь, что в вашем редакторе отключено добавление пробелов в конце строк (trailing whitespace).
- **Соавторство:** Если вам помогал GigaCode при создании PR, добавьте в комментарий к коммиту строку `Co-Authored-By: GigaCode <gigacode@sber.ru>`.

## Как предложить изменение (через браузер)

1.  Перейдите на страницу вашего репозитория `awesome-gigacode` на GitHub.
2.  Откройте файл `README.md`.
3.  Нажмите на иконку карандаша (Edit this file).
4.  Внесите изменения, соблюдая правила выше.
5.  В разделе «Commit changes» кратко опишите, что вы изменили (например, `Add link to GigaCode CLI commands`).
6.  Нажмите «Propose changes» и создайте Pull Request.

## Обновление Pull Request

Иногда мейнтейнер (владелец списка) может попросить вас исправить PR. Это нормально. Обычно это связано с опечатками или несоответствием формату. Вы можете внести правки в ту же ветку, и PR обновится автоматически.

## Кодекс поведения

Участвуя в этом проекте, вы соглашаетесь соблюдать уважительное и конструктивное общение. Мы не приемлем оскорблений или дискриминации в любой форме.

Спасибо за ваш вклад!
